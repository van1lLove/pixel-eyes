# Исходники Pixel Eyes

Из этих файлов собирается `pixel_eyes.plugin`. Ядро на Java компилируется в DEX и вшивается в Python-шаблон строкой base64, поэтому в самом плагине ядро выглядит как длинная строка.

Хуков в клиенте нет: ядро ничего не перехватывает, а только кладёт свою вью в окно приложения, слушает касания, набор текста и события чата.

## Сборка

Нужны JDK 11 или новее, Android SDK (любая свежая платформа и build-tools) и Python 3.

```bash
export ANDROID_HOME=/путь/к/Android/Sdk
bash build.sh
```

Готовый плагин появится в `out/pixel_eyes.plugin`. Если `java` нет в PATH, задайте ещё `JAVA_HOME`. Скрипт работает в Linux, macOS и Git Bash на Windows.

Плагин из релизов собран на JDK 21 и build-tools 37.0.0 (платформа android-36.1). С теми же версиями должен получиться тот же `classes.dex` байт в байт: сравните строку ядра в своём плагине и в скачанном.

## Что где

- `pixel_eyes.template.py`: Python-часть. Загружает ядро, строит экран настроек, пишет журнал. Метка `"@@DEX@@"` при сборке заменяется на ядро.
- `src/com/pixeleyes/`: ядро на Java.
  - `EyesCore`: всё, что зовёт Python.
  - `Overlay`, `CallbackWrapper`: вью поверх окна, касания, набор, события чата, тряска, буфер обмена.
  - `EyesView`: сама вью, тычки и перетаскивание.
  - `Brain`: внимание, эмоции, сон, частицы. `Face`: состояние лица на один кадр.
  - `Renderer`: рисует кадр в пиксели.
  - `Skin`, `MiniJson`: формат глаз в JSON.
  - `Mood`: настроение текста сообщения (гадости, любовь, смех, грусть).
  - `Panels`, `Editor`, `Ui`: живой пример, галерея и редактор в настройках.
  - `Config`: настройки из Python.
  - `Builtins`: встроенные глаза, генерится из `skins/` при сборке.
- `skins/`: встроенные наборы глаз.
- `tools/gen_builtins.py`: `skins/` в `Builtins.java`, его зовёт `build.sh`. `make_skins.py` генерит часть встроенных наборов, `make_catalog.py` собирает каталог в корне репозитория.
- `test/`: проверки без телефона.
  - `bash test/run.sh`: ядро на обычной JVM.
  - `python test/plugin_harness.py`: Python-часть на заглушках, запускать после сборки.
  - `node test/parity.js skin.json`: сверка движка сайта с Java (отпечатки кадров должны совпасть с `JsParity.java`).
